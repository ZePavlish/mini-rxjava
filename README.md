# Реализация библиотеки mini-rxjava
##Введение
В данном проекте была реализована простая версия библиотеки RxJava, основанная на принципах реактивного программирования. Цель проекта — создание библиотеки для асинхронной обработки потоков данных, которая поддерживает подписку на события, обработку ошибок и завершение потоков.

## Архитектура системы
Архитектура системы состоит из нескольких ключевых компонентов:

Observable: представляет собой поток данных, на который могут подписываться наблюдатели. Он генерирует события и управляет их распространением.

Observer: представляет собой подписчика, который получает данные от Observable. Он обрабатывает полученные данные, ошибки и завершение потока.

Schedulers: отвечают за выполнение операций на разных потоках или в основном потоке.

Система состоит из трех основных классов:

Observable — класс для создания и управления потоком данных.

Observer — интерфейс для реализации различных типов наблюдателей.

TestObserver — вспомогательный класс для тестирования, который реализует интерфейс Observer и собирает все данные, ошибки и статус завершения потока.

## Принципы работы Schedulers
Schedulers в реактивном программировании отвечают за то, на каком потоке будет выполнена операция. Они позволяют переносить выполнение операций на другие потоки, чтобы избежать блокировки основного потока. В данном проекте использовались следующие типыSchedulers:

Schedulers.io(): используется для работы с асинхронными задачами, которые не блокируют основной поток, например, для сетевых запросов или операций ввода-вывода.

Schedulers.computation(): используется для выполнения вычислений, которые не требуют долгого времени, но могут быть параллельно распределены на несколько потоков.

Schedulers.mainThread(): используется для выполнения операций в основном потоке, например, для обновления UI.

## Пример использования библиотеки
Пример использования библиотеки для создания Observable и подписки на него:

```
Observable<Integer> observable = Observable.create(emitter -> {
    emitter.onNext(1);
    emitter.onNext(2);
    emitter.onComplete();
});

TestObserver<Integer> testObserver = new TestObserver<>();
observable.subscribe(testObserver);

System.out.println(testObserver.getValues());  // Выведет: [1, 2]
System.out.println(testObserver.isCompleted());  // Выведет: true
```

В этом примере создается Observable, который генерирует два значения, а затем завершает поток. Наблюдатель получает эти значения и проверяет, завершился ли поток.

## Заключение
В ходе реализации библиотеки mini-rxjava была продемонстрирована базовая функциональность реактивного программирования с использованием Observable и Observer. Также была реализована поддержка различных типов потоков с использованием Schedulers.
